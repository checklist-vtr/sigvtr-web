# SIGVTR — Integração do Favicon v1.6.2

## Conteúdo

Este pacote contém os arquivos HTML revisados enviados pelo usuário, além dos ícones e manifests atualizados.

## Estrutura

- `index.html`: Checklist Mobile
- `manifest.json`: manifest do Checklist Mobile
- `favicon.ico`: favicon principal da raiz
- `assets/icons/`: ícones do Checklist Mobile
- `admin/`: páginas revisadas do Painel Administrativo
- `admin/manifest.json`: manifest do Painel Administrativo
- `admin/assets/icons/`: ícones do Painel Administrativo

## Instalação

Substitua os arquivos correspondentes no projeto, preservando os diretórios `css/`, `js/`, `assets/css/`, `assets/js/` e demais arquivos já existentes.

Os links receberam `?v=1.6.2` para reduzir o uso de cache antigo pelo navegador.

Após publicar no GitHub Pages:

1. Aguarde a atualização.
2. Feche a aba antiga.
3. Abra novamente o endereço.
4. Pressione `Ctrl + Shift + R`.
5. Se necessário, teste em janela anônima.

## Observação

O pacote não contém CSS e JavaScript do projeto porque eles não foram enviados nesta etapa. Ele deve ser aplicado sobre o projeto existente.
