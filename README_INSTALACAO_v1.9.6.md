# Instalação — SIGVTR v1.9.6

1. Substitua todos os arquivos do frontend no GitHub Pages.
2. Confirme que index.html, js/app.js, css/style.css e sw.js foram atualizados.
3. Abra o sistema com `?v=1.9.6-build2`.
4. No Android instalado como PWA, feche o aplicativo, limpe os dados do site ou remova e reinstale o atalho.
5. Confirme no topo a versão v1.9.6.

## Testes

- O seletor deve listar 50-2001 até 50-2021 e Outros.
- Outros em Viatura deve abrir o campo numérico de prefixo.
- Outros em Turno deve abrir o campo Operação / turno informado.
- Inserir foto do painel deve abrir diretamente a câmera ou seletor de imagem.
