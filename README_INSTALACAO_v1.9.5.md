# Instalação — SIGVTR v1.9.5

1. Substitua integralmente os arquivos do frontend no GitHub Pages.
2. Substitua integralmente `Código.gs`, `Complemento_Mobile_v4.gs` e `Avarias_Pendentes.gs` no Apps Script.
3. Na aba RETIRADAS, recomenda-se criar as colunas `Posto/Graduação` e `Operação/Outros`. Se não existirem, os dados permanecem preservados em `ITENS_JSON`.
4. Salve, teste em `/dev` e publique nova versão da implantação `/exec`.
5. Abra o sistema com `?v=1.9.5` e, no Android, feche/reabra ou reinstale o PWA se necessário.
