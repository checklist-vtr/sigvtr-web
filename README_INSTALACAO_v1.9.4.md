# Instalação — SIGVTR v1.9.4

1. Substitua integralmente os arquivos do frontend no GitHub Pages.
2. No Apps Script, substitua integralmente `Código.gs`, `Complemento_Mobile_v4.gs` e `Avarias_Pendentes.gs` pelos arquivos de `backend_apps_script/`.
3. Salve o projeto e teste a URL `/dev`; o campo `packageVersion` deve retornar `1.9.4`.
4. Publique uma nova versão da implantação `/exec`.
5. Abra o checklist com `?v=1.9.4` e atualize o PWA.
6. Faça um envio de teste para cada opção de turno.
